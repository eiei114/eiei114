## Project Overview

This is eiei114's GitHub profile repository - a special repository where the README.md displays as the user's GitHub profile page. It showcases OSS contributions, social links, and GitHub statistics for Keisuke Kawano.

## Repository Structure

- **README.md** - The profile content displayed on GitHub (HTML/Markdown with badges and stats)
- **.mcp.json** - MCP server configuration for development tools (GitHub, ClickUp, Notion, Pencil, WakaTime)

## Development Notes

- This is a static content repository with no build, test, or lint commands
- Changes to README.md are immediately reflected on the GitHub profile page
- The README uses GitHub-flavored Markdown with embedded HTML for layout
- Badge images are sourced from external services (shields.io, github-readme-stats, zenn.badge.nikaera.com)
